# Industry hero video assets

Place one individually licensed MP4 file in this folder for each industry:

- `automobile.mp4`: automotive production line, robotic assembly or precision automotive machining.
- `electronics.mp4`: electronics/semiconductor manufacturing or precision PCB assembly.
- `medical.mp4`: medical-device or precision medical-equipment manufacturing.
- `aerospace.mp4`: aircraft/aerospace component machining or turbine manufacturing.

## Production requirements
- Use stock footage whose individual page and licence permit commercial website use.
- Prefer footage without visible third-party logos, branded equipment, identifiable faces or audio.
- Download the original MP4 from the provider; do not hotlink or embed a third-party player.
- Use a landscape 16:9 clip, ideally 1920x1080, H.264 MP4, 24–30 fps.
- Trim to a seamless 8–15 second loop; remove audio; keep each file reasonably compressed (target 5–12 MB).
- Keep a record of each source page, creator, download date and licence in the asset register before publishing.

Suggested source: Pexels Videos. Its current licence permits commercial website use, but depicted trademarks, brands and people can have separate rights. Review each clip individually.

The React hero uses a poster image until the local MP4 is present and playable. Add the four MP4 files here to activate the moving backgrounds.
